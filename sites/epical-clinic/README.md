```bash
cd sites/epical-clinic
pnpm install
pnpm dev         # http://localhost:3000 (ES)  |  /en (EN)
```

## Finish the build (on your machine with open internet)

Run these three skill commands from the repo root, in order:

```
/design-system-generator      # mode B — extract from https://epicalclinic.es/
/ui-ux-pro-max                # already generated; re-run if tone needs adjustment
/web-builder                  # download photos from site + GMB into sites/epical-clinic/public/images/
```

Then:

1. Replace the pink/lavender tokens in `src/app/globals.css` with the extracted primary / accent colors (keep the client's real brand color).
2. Drop the downloaded photos into `public/images/` per `public/images/.gitkeep`.
3. Update `src/lib/site.ts` with the real address, phone, hours, Google rating from GMB.
4. Run `pnpm build` — this produces `out/` (static HTML). Zip it, import into GoHighLevel.
5. Or deploy to Vercel: `vercel --prod` for a live preview URL to send the client.
